# Dibral Chopp — visual world (redesign)

## Scope
Whole app, mode Operate. Desktop only, one user. Screens: Login, Painel, Reservas (grid), Clientes, Estoque, Sugestão, Fechamento.

## Audience, job, constraints
One person at the Dibral desk. Long Monday sessions typing reservations by client code; quick daily visits for fechamento and stock. Light, office daylight. Logo file not yet supplied: wordmark text with a logo slot, never an invented mark.

## Direction contract

THESIS: The reservation grid is a tiled boteco wall: every cell is a square tile with a thin grout joint, read by code first. Refuses the category default of a soft-card SaaS dashboard and the previous dark amber "chopeira".
OWN-WORLD: Porcelain-white ground (#f4f6f3), pure white tiles, grout lines #d6ddd6, bottle-green shell (#12503e) with ink #14241e, orange (#d9532c) only for selection, focus and attention, tile-blue/green/grey for status. Product brand colors appear as the decorative tile band on each chopp column head. Barlow body, Barlow Semi Condensed for headings and numerals. Square corners (2px), no soft shadows, hydraulic-tile SVG pattern used only on the rail foot and login.
STORY: The user knows within a second which week, which clients, which cells are filled, delivered or missing; code is the key, name second; alerts say what to do.
FIRST VIEWPORT: Left green rail 232px (wordmark slot top, six nav items, tile pattern at foot). Main: page title and week navigator on one line, search/sort toolbar, then the grid filling the width: sticky code and name columns, one column per chopp with a brand-colored band on its head, number cells with grout joints, totals row pinned at the bottom. Primary action sits at the right of the toolbar.
